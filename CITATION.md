# Citation

The study is an unpublished manuscript. Final author names, bibliographic details, repository URL and archive DOI must be supplied by the author when the repository is released. No journal acceptance or study DOI is implied by this package.

Until a release DOI exists, cite the actual repository URL, release tag and commit used, once those have been created. Do not cite a placeholder DOI.

For the EEG data, cite:

Delorme, A. EEG data from an auditory oddball task [dataset]. OpenNeuro, version 1.1.2. <https://doi.org/10.18112/openneuro.ds003061.v1.1.2>.

The source metadata's `HowToAcknowledge` field refers to the initial v1.0.0 release. This study used the version-specific v1.1.2 identifier above. Original metadata are retained unchanged.

Method citations and DOI links extracted from the current manuscript bibliography are provided in `docs/METHOD_REFERENCES.md`. Use those sources when interpreting the implementations; comparator rows are not claims to have replicated every original paper's complete protocol.
